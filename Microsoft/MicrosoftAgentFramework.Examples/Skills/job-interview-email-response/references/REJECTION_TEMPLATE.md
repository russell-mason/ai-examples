# JOB REJECTION EMAIL TEMPLATE

- Use the following template to write a job rejection email
- Note that anything not between [ and ] is literal text and should not be changed in any way
- Only fill in the placeholders, i.e. values between [ and ], with the provided information
```
To: [recipient-email]
From: j.smith@example.com
Date: [sent-date]
Subject: Job interview for [job-title] at Example Co.

Dear [recipient-name],

We regret to inform you that you have not been selected for the position of [job-title] at Example Co. 

We appreciate the time and effort you put into the interview process and wish you the best in your future endeavors.

Yours sincerely
John Smith
HR Manager
```
