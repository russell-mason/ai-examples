# JOB OFFER EMAIL TEMPLATE

- Use the following template to write a job offer email
- Note that anything not between [ and ] is literal text and should not be changed in any way
- Only fill in the placeholders, i.e. values between [ and ], with the provided information

```
To: [recipient-email]
From: j.smith@example.com
Date: [sent-date]
Subject: Job Offer for [job-title] at Example Co.

Dear [recipient-name],

We are pleased to offer you the position of [job-title] at Example Co. 

Your start date will be [start-date], and you will report directly to [manager-name].

Please review the terms and conditions of this offer and reply with your acceptance.

Yours sincerely
John Smith
HR Manager
```
